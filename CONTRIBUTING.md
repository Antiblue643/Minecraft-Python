# Contributing

Contributions are welcome for:

- Bugs, except bugs implemented as parody.
- Optimizations.
- Parody fixes for the Java version that McPy currently targets. Parody fixes
  for future Java versions will be put off for later.

Please keep big updates to me. If you have an idea for a larger
change, check with me before starting work on it.

The target version is `beta 1.1_02`

### *Please don't force-push!*
